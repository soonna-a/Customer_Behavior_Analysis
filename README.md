
# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, understand customer preferences, compare spending habits, and evaluate the impact of discounts and subscription status on revenue.

The project uses **SQL, Python, and Power BI** to perform data analysis and present insights through an interactive dashboard.

## 🎯 Project Objectives

- Analyze revenue generated by male and female customers.
- Identify customers who use discounts but spend above average.
- Find top-rated and most-purchased products.
- Compare spending across shipping methods.
- Analyze purchasing behavior of subscribers and non-subscribers.
- Evaluate discount usage across products.
- Segment customers based on previous purchases.
- Understand repeat purchasing behavior.
- Analyze revenue contribution across age groups.

- **SQL:** PostgreSQL

## 📊 Dataset Description

The dataset contains **3,900 customer purchase records** and includes information such as:

- Review rating
- Subscription status
- Shipping type
- Discount and promo code usage
- Previous purchases
- Payment method
- Purchase frequency

## 🔍 SQL Analysis

The SQL analysis covers the following business questions:

1. What is the total revenue generated by male vs. female customers?
2. Which customers used a discount but still spent more than the average purchase amount?
3. Which five products have the highest average review rating?
4. How do average purchase amounts compare between Standard and Express Shipping?
5. Do subscribed customers spend more than non-subscribers?
6. Which five products have the highest percentage of purchases with discounts applied?
7. How can customers be segmented into New, Returning, and Loyal groups?
8. What are the top three most-purchased products within each category?
9. Are repeat buyers more likely to subscribe?
10. What is the revenue contribution of each age group?

The project uses SQL concepts such as:
- Aggregate functions: `SUM()`, `AVG()`, `COUNT()`
- Grouping and filtering: `GROUP BY`, `WHERE`, `HAVING`
- Subqueries
- Conditional logic using `CASE`
- Common Table Expressions (CTEs)
- Window functions such as `ROW_NUMBER()`
- Sorting and limiting results

## ⚙️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Customer-Shopping-Behavior-Analysis.git
```

### 2. Set up PostgreSQL

- Install PostgreSQL and pgAdmin.
- Create a database named `Customer_behavior`.
- Import the CSV data into the `public.customer` table.
- Open the SQL file in pgAdmin and execute the queries individually.

### 3. Run the Python notebook

- Open the `.ipynb` file in Google Colab or Jupyter Notebook.
- Upload the dataset if required.
- Run the notebook cells sequentially.

### 4. Open the Power BI dashboard

- Open the `.pbix` file in Power BI Desktop.
- Configure the PostgreSQL connection if prompted.
- Refresh the data to view the latest results.
